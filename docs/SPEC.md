# SPEC — comfy-server (удалённый AI-воркстейшн за Tailscale)

> Собрано в брейншторме с Владом 2026-07-23 (роль Гипномастера). Это инфра/сетап-проект (не кодовый продукт) — ТЗ + runbook. Пошаговая установка — [SETUP-WINDOWS.md](SETUP-WINDOWS.md). Задачи — на доске ([TODO.md](../TODO.md) / [BACKLOG.md](../BACKLOG.md)). Проект пока вне workspace.

## 1. Суть

Удалённый **приватный** доступ к **локальной Windows-машине с мощной GPU** (закуплена специально под это) для AI-генерации. Механика «как агентская ось, но под ComfyUI». Приоритет функций: 1) **ComfyUI**, 2) **файловый доступ**, 3) **серверные загрузки по URL**. Пользователи — Влад + Даниил.

## 2. Компоненты (4 сервиса на машине)

| Сервис | Роль | Адрес (Tailscale MagicDNS) |
|---|---|---|
| **Tailscale** | приватная сеть/доступ; порты наружу НЕ открываем | — |
| **ComfyUI** (`--listen`) | генерация | `http://gpubox:8188` |
| **Filebrowser** | файлы: смотреть / **открывать-превью в браузере клиента** / переименовывать / создавать / редактор | `http://gpubox:8080` |
| **aria2 + AriaNg** | «дай URL → машина сама качает файл к себе» | `http://gpubox:6880` |

Все 4 — **автозапуск службами через NSSM** (переживают ребут, не надо подходить к машине). `gpubox` — MagicDNS-имя вместо голого IP.

## 3. Доступ и безопасность

- Доступ **только через Tailscale** (tailnet Влада; Даниил — добавить его устройство / node sharing). Порты в интернет **не открываются**.
- ComfyUI **без встроенной авторизации** → защищён приватностью tailnet (до него дотянутся только твои устройства).
- ⚠ Кастом-ноды ComfyUI = произвольный код → ставить **только доверенные** (известные репозитории), даже за Tailscale.

## 4. Что делаем и что НЕ делаем

- ✅ Просмотр/открытие файлов **в браузере клиента** (фикс проблемы агентской оси, где файл открывался физически на серверной машине).
- ✅ **Серверная закачка по URL** (aria2) — тяжёлые файлы качает сама машина, не через наш канал.
- ❌ **Загрузку тяжёлых файлов ЧЕРЕЗ систему не делаем** (файлы огромные).
- ❌ Свою обёртку-портал на старте не делаем; максимум — **стартовая страница** со ссылками или лёгкий реверс-прокси **Caddy** (`gpubox/comfy`, `/files`, `/dl`) — опционально, потом.
- Мультиюзер = **общая очередь ComfyUI** (для команды нормально; изоляция на каждого — это несколько инстансов, не нужно).

## 5. Доступ по адресам

По умолчанию **4 адреса по портам** (`http://gpubox:8188`, `:8080`, `:6880`). Единый вход (`gpubox/comfy`, `/files`, `/dl`) через Caddy или одну стартовую HTML-страницу — опциональная косметика на потом.

## 6. GPU

Локальная дорогая машина с мощной GPU, закуплена под задачу — узкого места по железу нет. ОС — **Windows**.
