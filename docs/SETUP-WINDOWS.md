# SETUP-WINDOWS — пошаговый сетап comfy-server

> Runbook установки под Windows к [SPEC.md](SPEC.md). Всё разворачивается на локальной GPU-машине; доступ — через Tailscale. Точные команды/версии сверять при установке (context7 для актуальных доков).

## 0. Предусловия
- Windows-машина с NVIDIA GPU (драйверы + CUDA актуальны).
- Права администратора (для установки служб NSSM).

## 1. Tailscale (сеть и доступ)
1. Установить Tailscale на GPU-машину → залогиниться в свой tailnet.
2. Установить Tailscale на устройства Влада и Даниила (или расшарить ноду — Tailscale node sharing).
3. В админке Tailscale включить **MagicDNS**, задать машине имя (напр. `gpubox`).
4. Проверка: с ноутбука `ping gpubox` (или заход по `http://gpubox:...` после шага 2).

## 2. ComfyUI (генерация)
1. Установить ComfyUI (portable/из репо), проверить локально на `127.0.0.1:8188`.
2. Запускать с флагом раздачи в сеть: `--listen 0.0.0.0 --port 8188` (снаружи доступен только через Tailscale).
3. Обернуть в **службу NSSM** (см. §5): автозапуск, рестарт при падении.
4. Проверка: `http://gpubox:8188` с ноутбука.
> ⚠ Кастом-ноды — только доверенные.

## 3. Filebrowser (файлы)
1. Скачать Filebrowser (Windows-бинарник).
2. Настроить: корневая папка(и), свой логин/пароль, порт (напр. `8080`).
3. Служба NSSM.
4. Проверка: `http://gpubox:8080` — браузишь диск, открываешь/превьюишь файлы у себя, переименовываешь/создаёшь.

## 4. aria2 + AriaNg (серверные загрузки по URL)
1. Установить **aria2**, запустить в RPC-режиме (`aria2c --enable-rpc --rpc-listen-all` + секрет токена).
2. Поднять **AriaNg** (статичный веб-UI) на порт (напр. `6880`), указать RPC-адрес aria2.
3. Службы NSSM (aria2 + отдача AriaNg).
4. Проверка: в AriaNg вставить URL → файл качается в файловую систему машины.

## 5. Автозапуск службами (NSSM)
Для каждого сервиса (ComfyUI, Filebrowser, aria2, AriaNg):
1. `nssm install <ИмяСлужбы>` → указать исполняемый файл + аргументы + рабочую папку.
2. Настроить автозапуск и авто-рестарт.
3. `nssm start <ИмяСлужбы>`.
4. Проверить, что после **перезагрузки** машины все 4 адреса живые сами.

## 6. (Опционально) Единый вход
- **Caddy** на машине: реверс-прокси `gpubox/comfy → :8188`, `/files → :8080`, `/dl → :6880`.
- Либо одна **стартовая HTML-страница** с тремя кнопками-ссылками (без прокси).

## 7. Финальная проверка
- [ ] Заход со своего ноутбука и **от Даниила** по `gpubox:порт`.
- [ ] Тест генерации в ComfyUI.
- [ ] Тест открытия/переименования файла в Filebrowser.
- [ ] Тест закачки по URL в AriaNg.
- [ ] Ребут машины → все 4 сервиса поднялись сами.
